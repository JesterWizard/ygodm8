# Session Log — 2026-07-13

## Trunk sub-menu extension framework

**Worked on:** Replaced the vanilla 3-option trunk sub-menu (`Trunk_A_Submenu`) with an extensible framework supporting up to 5 additional custom options (8 total). Existing 3 vanilla options (Details, Move to Deck, Return to Trunk) remain unchanged.

### Files

- `include/global.h` — extended `TRUNK_CURSOR_*` enum with `TRUNK_CURSOR_CUSTOM_START` and `TRUNK_CURSOR_MAX` (7)
- `src_custom/trunk_hooks.c` — added framework:
  - `TrunkSubMenuOption` struct + registration table (`gTrunkSubMenuCustomOptions[]`, `gTrunkSubMenuCustomCount`)
  - `Trunk_A_Submenu__Replacement` — full LynJump replacement of the sub-menu loop with dynamic option count, cursor OAM, and A-button dispatch
  - Extended tilemap rendering for custom option rows (`TrunkSubMenu_RenderCustomOptions`)
  - Handlers: `TrunkSubMenu_SelectDetails`, `TrunkSubMenu_SelectAddToDeck`, `TrunkSubMenu_SelectRemoveFromDeck`
- `src_custom/LynJump.event` — wired `Trunk_A_Submenu__Replacement` at ORG `$8854`
- `asm/ram_map_ewram.s` — allocated `gTrunkSubMenuCustomCount` (1 byte, 4-byte aligned) and `gTrunkSubMenuCustomOptions` (40 bytes)

### Outcome

ROM links and validates. Framework is inert by default (`gTrunkSubMenuCustomCount == 0`), preserving vanilla behaviour. To register options, populate the table and set the count from any init path.

## Sub-menu custom option positioning fix

**Worked on:** Shifted the 4th option ("Add to E. Deck") text rendering up by 2 tiles. Discovered that the pre-baked tilemap (`gUnk_808C240`) had blank entries at rows 15-18 — the 3rd vanilla option "Return to Trunk" was never visually rendered. Changed `TrunkSubMenu_RenderCustomOptions` loop to only render custom options (skipping the unused option-2 slot), and offset their rows by -2 (rows 15-16 instead of 17-18 for the first custom option).

### Files

- `src_custom/trunk_hooks.c` — `TrunkSubMenu_RenderCustomOptions` loop now uses `optIdx = TRUNK_SUB_MENU_VANILLA_COUNT + k` with `topRow = 11 + 2 * optIdx - 2` so first custom option occupies the previously-blank rows 15-16

### Outcome

ROM builds. 4th option text now renders 2 tiles higher (rows 15-16 instead of 17-18), which is within the visible menu area.
