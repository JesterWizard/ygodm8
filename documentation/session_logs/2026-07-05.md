# Session Log — 2026-07-05

## Fix turn counter frozen at 0

**Worked on:** Board turn counter stayed at 000 for entire duels. `gDuelBoardTurnCount` was allocated at odd IWRAM `0x03007559`; ARM7 misaligned u16 reads/writes left the value at 0 despite `BeginDuelBoardTurn()` incrementing.

**Root cause:** Single-byte pad before the u16 did not flip bump-cursor parity after preceding 1-byte flags (`gDoubleSummonExtraSummonUsed`, etc.).

**Fix:** Changed `gDuelBoardTurnCountPad` from 1 to 2 bytes so the counter lands at `0x03007558` (even).

**Files:** `asm/ram_map_iwram.s`

**Outcome:** `make all` passes; RAM validator no longer flags `gDuelBoardTurnCount`.

**Open / next:** Playtest turn counter increments on each turn start.

## Fix stage modifiers not updating mini-card ATK/DEF

**Worked on:** Spellbinding Circle / Shadow Spell stage debuffs and Hourglass of Life stage buffs updated the stage stamp but not ATK/DEF digits on field mini-cards.

**Root cause:** (1) `RefreshFieldMonsterStatOverlays` returned early whenever `gHideEffectText` was set, so `Duel_RefreshMonsterStatOverlays()` during flip/trap effects was a no-op while effect text was queued. (2) `ZoneShowsCombatStats` called `GetTypeGroup` → `SetCardInfo`, clobbering stage-modified stats mid-pipeline (same class of bug as Harpie Lady 1). (3) Stage increment/decrement hooks used full `ShouldBlockEffectOnZone`, blocking beneficial increments in edge cases.

**Fix:** Refresh overlays during real gameplay even when effect text is hidden (still skip during `gAiSimInBatch`). Gate combat stats via `gCardData_NEW[].type` instead of `GetTypeGroup`. Narrow stage hooks: decrements keep harmful-target + spell-immune guards only; increments unguarded. Refresh stat overlays after every spell/trap effect resolve. Tripper Mercury drain reads printed ATK from card data instead of `SetCardInfo`.

**Files:** `src_custom/mini_card_hooks.c`, `src_custom/card_hooks.c`, `src_custom/card_passive_hooks.c`, `src_custom/spell_effect_hooks.c`, `src_custom/permanent_effects/the_tripper_mercury.c`, `tests/host/test_mini_card_stats.py`

**Outcome:** `make all` passes; host mini-card stat tests updated.

**Open / next:** Playtest Hourglass flip (+500 ATK on all your monsters) and Spellbinding Circle activation (-500 ATK on opponent row).

## Hourglass gfx still early — suppress LP gfx before popup

**Worked on:** Stat boost still visible before Hourglass popup finished.

**Root cause:** `Duel_ChangeLp(..., TRUE)` called `UpdateDuelGfxExceptField()` before `Duel_ShowEffectTextTyped`, refreshing mini-card ATK while text was still typing. Vanilla uses `HandleAtkAndLifePointsAction` without a field refresh until `sub_8041CCC` completes.

**Fix:** Hourglass / Injection Fairy Lily use `Duel_ChangeLp(..., FALSE)`; drop explicit pre/post refresh — `sub_8041CCC` refreshes field when popup dismisses.

**Files:** `hourglass_of_life.c`, `injection_fairy_lily.c`, `karate_man.c`, `tests/host/test_mini_card_stats.py`

**Outcome:** `make all` passes.
