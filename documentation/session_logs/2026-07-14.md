# Session Log — 2026-07-14

## Fixed: Stale baked "Return to Trunk" text at rows 15-16 in shifted sub-menu

**Problem**: The pre-baked tilemap (`gUnk_808C240`) at rows 15-16 contains tile entries for the vanilla 3rd option ("Return to Trunk") pointing to tiles 101-120. The shifted render loads "Return to Trunk" glyph data at tiles 101-140 (to fix missing glyphs for the shifted option 2 at rows 13-14), which also makes these stale baked entries at rows 15-16 valid, showing "Return to Trunk" over the first custom option.

**Fix**: Added a clear loop in `TrunkSubMenu_RenderVanillaShifted()` that writes blank tiles (tile index 0 with correct palette bits `r7`) at rows 15-18, columns 9-28. This erases the stale baked "Return to Trunk" entries before the custom render overwrites rows 15-18 with actual custom option text.

**Files touched**:
- `src_custom/trunk_hooks.c` — Moved `r7` out of inner block scope so it's accessible for the new clear loop; added `sub_800800C` loop clearing rows 15-18.
