## Grand Jupiter ATK — stat pipeline post-hook fix

**Worked on:** Absorb worked (Zone Eater in backrow) but Jupiter stayed at 2500 ATK in info bar and mini-card.

**Root cause:** Bonus was only applied through `Duel_TryApplyDynamicZoneStats` → `TheGrandJupiter_ApplyDynamicZoneStats`. That path either returned early (no bonus) or never ran for Jupiter's normal stat display. Equip metadata used a board-cell index that did not reliably resolve Jupiter's zone when summing bonus ATK.

**Fix:** Store equip→Jupiter links as fixed row/col. Sum original ATK by matching Jupiter zone pointer. Apply bonus in `ApplyTheGrandJupiterEquipAtkBonus` from `card_hooks.c` (same pattern as Power Bond / Riryoku), after stage/field mods.

**Files:** `the_grand_jupiter.c/.h`, `ram_map_ewram.s`, `card_hooks.c`, `duel_helpers.c`, tests

**Outcome:** `make test-cards-build` passes.
