# Session Log — 2026-07-03

## 2026-07-03 — Duel trunk-view graphics API

**Worked on:** Card effects opening trunk/deck-menu views needed one shared entry/exit path so duel graphics always reload after closing the menu.

**API:** Added `DeckMenu_BeginDuelTrunkView()` / `DeckMenu_EndDuelTrunkView()` around card-opened deck menus. `End` runs `UpdateAllDuelGfx()` on every exit path. Non-graveyard card pickers use `DeckMenuMainPickConfirmWithLabels`, whose top-level B press waits a frame and does nothing so B cannot drop straight back to the field or spin-freeze the input loop.

**Callers:** Emergency Call, Fusion Recovery, fusion duel picker, Elemental HERO Ocean target menu, Elemental HERO Necroid Shaman graveyard menu.

**Outcome:** `make test-cards-build` passes.

## 2026-07-03 — Composable deck picker label API

**Worked on:** Refactor trunk pick submenu to compose from canonical option labels instead of separate preset blobs.

**API:** `DeckMenuMainPickConfirmWithLabels(labels, count)` with `DECK_MENU_PICK_LABEL_DETAILS`, `FUSION_SUMMON`, `SELECT_CARD` (up to 3). Fusion Summon and Select This Card share confirm behavior. **Callers:** Emergency Call + Fusion Recovery → Details + Select This Card; fusion duel → Details + Fusion Summon.

## 2026-07-03 — Plasma Vice hand-discard crash

**Worked on:** Game crashed when selecting a hand card to discard for Plasma Vice's effect.

**Root cause:** Same bug class as Wild Wingman — `Duel_DiscardFromHand` scrolls the field BG to the hand row, then generic `DUEL_CURSOR_PICK_ZONE` tried to scroll from the monster row, corrupting board scroll state.

**Fix:** Dedicated `DUEL_CURSOR_ELEMENTAL_HERO_PLASMA_VICE_TARGET` (38); `sub_8041E70(PLAYER_HAND, targetRow)` before destroy targeting; A/B wired like Wild Wingman.

**Outcome:** `make test-cards-build` passes.
