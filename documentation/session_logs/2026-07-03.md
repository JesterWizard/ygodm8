## 2026-07-03 — Plasma Vice hand-discard crash

**Worked on:** Game crashed when selecting a hand card to discard for Plasma Vice's effect.

**Root cause:** Same bug class as Wild Wingman — `Duel_DiscardFromHand` scrolls the field BG to the hand row, then generic `DUEL_CURSOR_PICK_ZONE` tried to scroll from the monster row, corrupting board scroll state.

**Fix:** Dedicated `DUEL_CURSOR_ELEMENTAL_HERO_PLASMA_VICE_TARGET` (38); `sub_8041E70(PLAYER_HAND, targetRow)` before destroy targeting; A/B wired like Wild Wingman.

**Outcome:** `make test-cards-build` passes.
