# Session Log — 2026-07-16

## Fixed: synchro frame palette overwritten by extended art palette

**Root cause:** The call order in `print_card.c` is `sub_80267E0()` then `CopyCardArtDataToBuffers()`.  
1. `sub_80267E0__Replacement` writes the synchro frame palette (40 bytes) to `gUnk_8E01368 + 0x40` (GBA palette bank 4, entries 64+).  
2. `CopyCardArtDataToBuffers__Replacement` then copies the card art palette (128 or **224** bytes for extended palette cards) to `gUnk_8E01368` starting at entry 0. With 224 bytes = 112 entries, it overwrites entries 64-111 (banks 4-6), destroying the frame palette. The art palette data at bank 4 is random frame-garbage, causing "splotches of black all over."

**Fix:** At the end of `CopyCardArtDataToBuffers__Replacement`, re-apply the frame palette (40 bytes to `gUnk_8E01368 + 0x40`) using `GetCustomCardColorPalette()` for new colors or `gUnk_8E137C4[]` for vanilla colors — same logic as `sub_80267E0__Replacement`.
