## 2026-07-02 — Wild Wingman restart on backrow select (follow-up)

**Worked on:** GBA soft-reset when confirming Spell/Trap destroy after hand discard.

## 2026-07-02 — Fixed Wild Wingman backrow targeting crash

**Worked on:** Crash when selecting a Spell/Trap after discarding for Wild Wingman’s effect.

**Root cause:** `DestroyTarget` duplicated PickZone cleanup (`TryActivatingPermanentEffects` etc.) while cursor state was still `DUEL_CURSOR_PICK_ZONE` — same bug class as Harpies Pet Baby Dragon. With opponent hand field scroll enabled, moving up from opponent backrow during targeting also overwrote `destY` to row 5 (out of `gFixedZones` bounds).

**Files:** `elemental_hero_wild_wingman.c`, `duel_opponent_hand_scroll_hooks.c`

**Outcome:** `make test-cards-build` passes. Resolver only destroys zone; PickZone handler owns cleanup. Opponent-hand scroll disabled while `gDuelCursor.state != 0`.
